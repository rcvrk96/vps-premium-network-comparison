## 精品线路里的"精品"，精在哪一段

AS9929 是中国联通的精品网骨干，业内直接叫"联通 9929"。它的卖点在回程路径：电信用户的回程流量先走联通 9929，到国内再落到电信 163 骨干；联通用户直连 9929；移动用户走 9929 转到移动 CMI。普通美国 BGP 机器晚高峰要和一大堆跨境流量抢同一条公共路由，9929 走的是运营商单独划出来的通道，丢包率和延迟抖动都小一截，这也是它常年被拿来建站和远程办公的原因。

再往上比一层。9929 和 4837（联通 A 网）经常被放在一起问，9929 的质量略高一档，价格也贵一点；4837 的优势在带宽给得大、单价低，对峰值延迟不那么敏感的业务更划算。CN2 GIA 是电信那条最贵的线，电信方向的回程质量比 9929 更极致，价格也更高。CMIN2（CMI-N2）是移动的精品线路，移动用户走这条基本等于走自家高速路。

这几条线的共同点是走运营商专用骨干，不跟普通互联网流量挤在一起。代价也一致：同样配置挂上这些线路就要加钱，端口带宽通常也不敢给太大。

## 什么情况下不用买 Evoxt

**目标是国内三网直连稳定。** 9929 的价值在回程路径本身，跟 CPU 主频关系不大。国内有商家把 9929 做成 200 元上下的年付入门款，1 核 1G、50Mbps 端口、200GB 月流量（丽萨主机的年付特价系列，价格来自公开页面整理，页面没有标注更新日期，下单前自己核对一遍）。Evoxt 的价格表里既没有端口速率也没有 9929 字样，它优化的是单核性能和单位价格。这两条路线解决的问题不一样，先想清楚你要的是回程路由还是算力。

**流量大、对延迟不敏感。** 4837 线路或者不限流量的方案更合适，单价低、带宽给得宽。9929 这类精品线路的端口带宽普遍不大，拿来跑大流量下载是浪费。

**只是当落地机或做测试。** $2.99 的 VM-0.5 足够，没必要为线路付溢价。

## 下单前确认清单

1. **计费周期。** 月付最灵活，预付一年以上才会出现周期折扣，折扣多少以结算页显示为准，别按记忆里的数字算预算。

5. **退款。** 新用户 7 天内可申请退款，具体条款以下单时的页面为准。拿不准就先月付，一周内把晚高峰跑一遍。
